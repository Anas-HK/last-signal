# LAST SIGNAL
Cooperative Twitch space rescue. Desktop streamer control room and 16:9 OBS game view. The streamer flies with WASD; Twitch chat uses !shield, !boost, !repair. Viewers appear as named drones beside the ship and earn mission credits. A 120-second rescue with three pods and a jump gate, real collisions and a shared resource economy. Rehearsal mode is explicitly marked SIMULATED CHAT. Real mode uses Twitch EventSub.

Visual language: utilitarian, cinematic, editorial mission control. Near-black navy #080d14, panels #101820, borders #26333c, warm white #edece5, muted #8b9aa4, amber #f5b65d primary, cyan #70ead8 shield, coral #fb7c70 danger. Geometric sans headings, system sans body, monospace small telemetry. Strong typography, generous margins, 1px rules; no generic dashboard cards or purple gradients. Tiny functional eyebrow labels and large memorable heading. Broad starfield playfield with hand-drawn vector spacecraft and asteroids, rescue rings, ethereal planet crescent, real-time energy beams. Right side narrow crew communications and roster. Three low-profile crew command strips below the game. Header brand left, connection status and connect Twitch right. Main top title: 'You fly. Chat keeps you alive.' Primary launch rescue button. Onboarding explains the two roles clearly. Mission conclusion credits each viewer. Rehearsal tools separate from live connection. Every button functional.
