## Video description

You fly. Chat keeps you alive.

LAST SIGNAL is a Twitch co-op space rescue. The pilot steers, fires a laser, dashes with fuel from chat, and fires caught power-ups with E. Viewers board with !join, supply !shield, !boost and !repair, send crates with !drop, or throw named meteors with !meteor. Three distinct viewers coordinating the three stations trigger ALL HANDS. Rescue three pods and bring 13 survivors home before the two-minute jump window closes.

This video shows the actual game with clearly labeled simulated chat, a keyboard-controlled crate pickup, and a complete uncut training-pilot rescue. The Twitch connection screenshot is from an actual read-only IRC join; zero viewer messages were received in that check. Earlier viewer-sent join, boost, shield and repair behavior is documented in the validation record. Viewer-sent drop and meteor commands have not been verified against real chat. OAuth/EventSub remains optional and fixture-tested.

The narration is synthesized offline. Game audio is not included in this export; the game has synthesized music and sound effects.

Built with OpenAI Codex. React, TypeScript, Canvas, Node, Twitch read-only IRC, and an OBS spectator view. No paid inference service or game engine required.
